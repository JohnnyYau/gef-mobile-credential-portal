# GEF mobile 宣传海报 — 设计 Brief（pure-image）

> v2 修订（用户要求海报注明所用技术）：卖点区改为「技术栈」四行（ML-DSA 抗量子签名 / RSA-PSS·ECDSA 双签发 / SHA3-512 链上哈希 / PDF 内嵌 JSON 载荷），底部加注「链上仅存哈希与签名 · 明文永不触链」；视觉语言、画幅、品牌、CTA 与 v1 保持一致。

- 任务：为 GEF mobile 凭证验证门户制作一张竖版宣传海报（2:3，1080×1620 PNG）。
- 主题：学历凭证，一秒验证；上传 PDF → 六项检查 → 链上存证 → 真实有效。
- 商品/核心对象：GEF mobile Credential Verification Portal（无实体商品；核心对象=文凭+验证印章+区块链存证）。
- 受众：雇主 HR、学校注册处、学生/毕业生。他们在意的：真伪确认快、不可篡改、可追溯、批量核验。
- 视觉主张：公证/可信感——奶油白纸感背景 + 金箔印章 + 墨黑文字 + 瑞士国际主义留白排版；中央主视觉为一枚烫金毕业文凭 + 环绕链环 + 大红「真实有效」印章。避免科技蓝刻板印象。
- 画幅与安全区：2:3 竖版；顶部 10% 品牌区，上部 26% 标题区，中部 38% 主视觉，下部 26% 技术栈+CTA；四周 5% 安全边距。
- 可见文字（唯一准确源，逐字核验）：
  - 主标题：“学历凭证，一秒验证”
  - 副标：“上传 PDF · 六项检查 · 链上存证”
  - 技术栈小节标题：“技术栈 TECHNOLOGY”
  - 技术栈四行：“ML-DSA 抗量子签名” “RSA-PSS · ECDSA 双签发” “SHA3-512 链上哈希” “PDF 内嵌 JSON 载荷”
  - 注脚：“链上仅存哈希与签名 · 明文永不触链”
  - 品牌：GEF mobile Credential Verification Portal
  - CTA：“上传 PDF，立即验证”
- 禁止项：不出现任何平台名/URL/二维码（无真实扫码需求）；无极限词；无编造日期地点人名；除上述文字外不生成任何其他字符；无水印。
- 质量：结构完整、文字清晰无乱码、边缘干净、目标尺寸 1080×1620。

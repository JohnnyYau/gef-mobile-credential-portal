## 1. 新增常量（`app/config.py`，第 80–94 行）

| 常量 | 类型 | 默认值 | 用途 |
|---|---|---|---|
| `CHAIN_SNAPSHOT_TIMEOUT` | int | 60 | 链快照恢复的网络读取超时（秒） |
| `LLM_DEEPSEEK_TIMEOUT` | int | 40 | DeepSeek API 调用超时（秒） |
| `LLM_OLLAMA_TIMEOUT` | int | 90 | 本地 Ollama 调用超时（秒） |
| `SMTP_TIMEOUT` | int | 10 | SMTP 连接/发送超时（秒） |
| `CHAIN_TAIL_LIMIT` | int | 10 | 公开链尾返回的区块数 |
| `NOTIFICATION_RECENT_LIMIT` | int | 10 | 通知日志视图保留条数 |
| `RAG_CITATION_LIMIT` | int | 3 | 离线回答中摘要引用的链上记录条数 |
| `REVOCATION_REASON_MAXLEN` | int | 200 | 链上撤销原因截断长度 |

这些是内部默认值，不暴露为环境变量覆盖；既有可配置项（`RATE_LIMIT_*`、`BATCH_ISSUE_MAX` 等）保持原 env 读取方式不变。
